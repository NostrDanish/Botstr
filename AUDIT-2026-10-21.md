# Security Audit — Botstr — 2026-10-21 (re-run)

## Summary

Re-run of the 2026-10-20 audit. **No code changes since the previous audit** (HEAD still 6f5bac0, latest commit 2026-09-19). Both CRITICAL/HIGH findings were re-verified directly against `worker.ts` today and remain **UNFIXED**: the entire management API (`GET/POST /api/bots`, PATCH/DELETE, start/stop/restart, logs/events, files) has no authentication, and `POST /api/bots/:id/export` still returns the bot's plaintext `nsecHex` plus all decrypted per-bot secrets to anyone who can reach the deployment.
